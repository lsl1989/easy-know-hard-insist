# Easy Know Hard Insist

> "易知难坚持" - 记录学习路上的点点滴滴

## 欢迎来到我的知识库

这是一个基于 [Docusaurus 2](https://docusaurus.io/) 构建的个人知识分享网站，记录学习过程中的心得、笔记和实践经验。

## 快速导航

### 📚 文档分类

- **[编程](/program)** - 编程语言、框架、工具等技术笔记
- **[数学](/math)** - 数学概念、公式推导、应用实例

### 🚀 快速开始

```bash
# 克隆项目
git clone https://github.com/lsl1989/easy-know-hard-insist.git

# 进入项目目录
cd easy-know-hard-insist

# 安装依赖
yarn install

# 启动开发服务器
yarn start
```

启动后访问 [http://localhost:3000](http://localhost:3000) 即可查看文档。

## 项目特点

- ✅ **易于维护** - 使用 Markdown 编写文档
- ✅ **快速部署** - 支持 GitHub Pages 自动部署
- ✅ **搜索友好** - 内置全文搜索功能
- ✅ **响应式设计** - 支持移动端访问
